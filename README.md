# Dennies Bor

**Computational Scientist | PhD Candidate @ George Mason University**

Developing physics-based models for infrastructure resilience and space weather impacts. Specializes in numerical simulations, econometric modeling, signal processing, and geospatial computing.

## Research Focus
- Computational physics (numerical methods, PDEs, particle dynamics)
- Econometric modeling (Input-Output, CGE, nonlinear optimization)
- Signal processing (spectral methods)
- Geospatial computing (hyperspectral imaging, satellite image analysis, remote sensing)

## Technical Stack
**Scientific Computing:** Python (NumPy, SciPy, Pandas), Pyomo, IPOPT, MATLAB  
**Geospatial:** GDAL, geopandas, rasterio, Leaflet, Cesium, ENVI, ArcGIS  
**Web Development:** React, Go, Node.js  
**Infrastructure:** AWS, GCP, Docker, GitHub Actions, Nginx

- [**Physics-Economic Coupling**](https://github.com/denniesbor/spw-geophy-io) - Integrated model for socio-economic impact assessment
